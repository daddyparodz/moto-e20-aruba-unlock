# Contributing

Pull requests from everyone are welcome.

This public repository intentionally has no GitHub Actions workflows. Maintainers review proposed changes, and contributors run the documented offline verification locally before submission.

Before opening a pull request, run the Linux checks from [the host guide](docs/LINUX_HOST.md). Keep device-specific claims tied to exact model, firmware, hashes, and hardware evidence. Never include credentials, personal device data, private signing keys, or USB debugging keys.
